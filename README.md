# Pragyan CTF 2026
## Directory Structure

```text
<Question_Category>/
└── <Question_Title>/
    ├── question.txt        # description shown to players
    ├── readme.md           # Official writeup
    ├── flag.txt
    ├── solve.py            # Exploit / solve script
    │
    ├── images/             # Images used in writeup file
    │
    ├── includes/           # Server-side deployment files
    │
    ├── release/            # Files given to participants
    |
    └── source/             # Source code
```

## Flag Format
Flags are in the format: `p_ctf{...}`
